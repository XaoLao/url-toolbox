# Roadmap

### Next
- Undo for delete actions
- JSON import and merge
- Better keyboard navigation
- Project-specific fields for Url Toolbox
- Empty-state examples that can be removed in one click

### After that
- Optional encrypted sync adapter
- Shareable read-only snapshots
- PWA install and offline cache
- Automated accessibility checks

### Not doing yet
- Accounts
- Billing
- A giant plugin marketplace

The point is to keep the useful path short.
